5. Yêu cầu kỹ thuật

Gom thành 4 nhóm để dễ chia việc.

Nền tảng và đa ngôn ngữ

  • WordPress: khách tự cập nhật sản phẩm, tin tức. Sản phẩm dùng custom post type + trường spec, nhãn (có sẵn/OEM, sống/chín, thị trường xuất khẩu) và nút ẩn hàng theo mùa/hết hàng.
  • 3 ngôn ngữ: EN mặc định, JP, VN. URL /en/ /ja/ /vi/. Nút chuyển ngôn ngữ giữ đúng trang tương ứng.
  • Font: hỗ trợ tiếng Nhật, ví dụ Noto Sans JP.
  • Responsive: desktop, tablet, mobile. Menu thu gọn trên mobile, nút hỏi giá luôn dễ bấm, 3 nút nổi gom thành 1 trên điện thoại.

SEO và AIO

  • Mỗi trang: title, meta description đủ 3 ngôn ngữ; alt ảnh; slug chữ thường có gạch nối.
  • Kỹ thuật: thẻ hreflang, sitemap.xml, robots.txt.
  • Schema: Organization, Product, BreadcrumbList.
  • AIO: nội dung có cấu trúc rõ (FAQ, bảng thông số), thông tin công ty nhất quán để AI search trích dẫn đúng.
  • Redirect 301: thu thập toàn bộ URL cũ của etf-vn.com, chuyển sang URL mới tương ứng.

Đo lường

  • BowNow: tracking toàn site, 4 form, trường ẩn (xem mục 4).
  • GA4 và Google Search Console.
  • Chuyển đổi: đo tại trang Thank-you.

Hosting, tốc độ, bảo mật

  • Hosting: máy chủ tại Việt Nam, SSL, backup tự động. Cân nhắc CDN để buyer ở Nhật, Mỹ, châu Âu tải nhanh.
  • Tốc độ: ảnh WebP + lazy load, video nhúng (không tự host file nặng), Core Web Vitals đạt mức tốt.
  • Bảo mật: plugin bảo mật, chống spam form, phân quyền tài khoản quản trị.
  • Pháp lý: trang Privacy policy, thông báo cookie cho buyer châu Âu.
